 ##Функционал проекта
 
Данный проект реалезует ряд функций.

С помощью класса Ingridient вы можете вводить продукты в систему в формате "Название продукта", его вес, "еденицы измерения". Так же в этом классе реализована функция сравнения двух ингридиентов (сравнение идет по еденицам измерения и названию продукта)

Класс Recipe позволяет составить рецепт блюда из нескольких (или одного) ингридиента. Так же реализована функция подсчета количества продуктов на несколько порций (умножение на коэф >0). Вывод информации о рецепте осузествляется в формате строки "Название блюда:", "Ингридиент","кол-во", "ед измерения", и тд по списку ингридинтов. 

Класс DietRecipe реализовывает функцию добавления специфического комментраия к рецепту блюда, рода "диетический","вегаский","без глютена","высокобелковый","специальные от Газана67" и тд. Эта функция основана на родительском классе, она лишь добаляет спицифику блюду.

Класс ShoppingList позволяет создать список продуктов для определенного блюда на определенное количетсво порций. В список можно добавлять несколько рецептов, так же их можно удалять. 

##Тестики
Для классов проекта написаны тесты, контролирующие корректоную работу программы. Каждый тест для определенного класса проверяет определенное условие, которое может стать угрозой для работы проекта. 

## Запуск проекта

### Windows

1. Распаковать архив проекта  
2. Открыть папку проекта  
3. Открыть терминал (PowerShell или CMD)  
4. Запустить тесты:

```bash
pytest
```

### macOS / Linux

1. Распаковать архив проекта  
2. Открыть папку проекта  
3. Открыть терминал в этой папке  
4. Установить pytest (если нужно):
    -python3 -m pip install pytest
5. Запустить тесты:
    -pytest
